Política de Privacidade

Última atualização: 27 de outubro de 2026

Esta política explica como o aplicativo Sincronia, para macOS, trata as informações dos usuários, inclusive os dados acessados pela conta do Google.

1. Que dados o app acessa

  • Arquivos e pastas do Mac que o usuário escolhe sincronizar: nomes, tamanhos, datas de modificação e conteúdo, apenas para comparar e copiar.
  • Google Drive, quando o usuário entra com a conta do Google (permissão https://www.googleapis.com/auth/drive): lista de arquivos e pastas, seus nomes, tamanhos, datas e somas de verificação (MD5), e o conteúdo dos arquivos que precisam ser enviados ou baixados.
  • Dados básicos da conta Google: nome, e-mail e espaço usado no Drive, mostrados ao próprio usuário no app.

2. Como os dados são usados

Os dados são usados exclusivamente para executar as sincronizações e downloads que o próprio usuário configura e inicia: comparar pastas, copiar, atualizar, mover para a lixeira e criar pastas. A Sincronia não usa os dados para publicidade, perfis, análises ou qualquer outra finalidade.

3. Onde os dados ficam

Todo o processamento acontece no Mac do usuário. A Sincronia não possui servidores e não envia dados a terceiros: as comunicações acontecem diretamente entre o Mac e os serviços do Google. A autorização de acesso (token) e as configurações das sincronizações ficam guardadas apenas no Mac do usuário, na pasta de dados do app.

4. Compartilhamento

A Sincronia não vende, aluga nem compartilha dados de usuários com ninguém.

5. Uso limitado dos dados do Google

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Como revogar o acesso

O usuário pode desconectar a conta a qualquer momento em Conta do Google → Sair da conta, no app, ou em myaccount.google.com/permissions. Apagar o app e sua pasta de dados remove todas as informações guardadas no Mac.
